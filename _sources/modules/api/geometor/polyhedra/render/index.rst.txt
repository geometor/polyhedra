.. py:function:: export_blender_script(solids: list[geometor.polyhedra.model3d.primitives.Solid3D], script_path: pathlib.Path, spacing: float = 4.5) -> pathlib.Path

   Emits a standalone Blender 5.x Python script generating a studio showcase.

   Creates collections, meshes, Principled BSDF materials (Boxwood, Alabaster,
   Gold), studio 3-point lighting, and camera framing.

   :param solids: List of Solid3D polyhedral models to include in the scene.
   :param script_path: Target filesystem path for the emitted Python script.
   :param spacing: Center-to-center offset along the X axis between models.

   :returns: Path to the generated Python script.


.. py:function:: export_ingetrazo_script(solids: list[geometor.polyhedra.model3d.primitives.Solid3D], script_path: pathlib.Path, spacing: float = 4.5) -> pathlib.Path

   Emits a runnable Python script for IngeTrazo 0.6.0 CAD modeler.

   Lays out polyhedra along the X-axis on named layers ('Platonic_Solida',
   'Leonardo_Vacua') with warm boxwood and alabaster materials.

   :param solids: List of Solid3D polyhedral models to include in the scene.
   :param script_path: Target filesystem path for the emitted Python script.
   :param spacing: Center-to-center offset along the X axis between models.

   :returns: Path to the generated Python script.


.. py:function:: export_obj_mtl(solid: geometor.polyhedra.model3d.primitives.Solid3D, obj_path: pathlib.Path) -> tuple[pathlib.Path, pathlib.Path]

   Exports a Solid3D to Wavefront .obj and companion .mtl material library.

   Maps face_roles ('base', 'outer_frame', 'window_reveal', 'inner_frame',
   'truncation', 'pyramid') to distinct Renaissance boxwood, alabaster, and
   stone material definitions.

   :param solid: Exact symbolic Solid3D polyhedral model.
   :param obj_path: Target filesystem path for the .obj file.

   :returns: Tuple of (obj_path, mtl_path).


.. py:function:: render_model2d_svg(model: geometor.model.Model, *, golden_segments: list[tuple[str, str, str]] | None = None, width: int = 520, height: int = 480, graphic_id: str = 'slice') -> str

   Renders a 2D GEOMETOR symbolic Model to publication-grade SVG.

   Renders circles, polygons, 3-vertex midpoint path segments, points, and
   labels with data-ref attributes using luminous gold and sky-blue theme
   colors with full dark-mode adaptation.

   :param model: Exact symbolic 2D geometor.model.Model instance.
   :param golden_segments: Optional list of (pt1_label, pt2_label, role) triples
                           designating golden ratio segments to highlight in gold or terracotta.
   :param width: SVG viewport width in pixels.
   :param height: SVG viewport height in pixels.
   :param graphic_id: Unique identifier for data-graphic-id attribute.

   :returns: Valid XML SVG string with class 'euclid-graphic'.


.. py:function:: render_net_svg(solid: geometor.polyhedra.model3d.primitives.Solid3D, *, width: int = 520, height: int = 420, graphic_id: str = 'net') -> str

   Renders unfolded 2D papercraft net layout of a Solid3D to SVG.

   Uses dual graph BFS unfolding from geometor.polyhedra.model3d.bridge,
   drawing filled face polygons, dashed interior hinge folds, solid boundary
   cut lines, and centered face index labels.

   :param solid: Exact symbolic Solid3D polyhedral model.
   :param width: SVG viewport width in pixels.
   :param height: SVG viewport height in pixels.
   :param graphic_id: Unique identifier for data-graphic-id attribute.

   :returns: Valid XML SVG string with class 'euclid-graphic'.


.. py:function:: render_solid_svg(solid: geometor.polyhedra.model3d.primitives.Solid3D, *, yaw_deg: float = 32.0, pitch_deg: float = 22.0, roll_deg: float = 0.0, camera_dist: float = 5.2, focal_length: float = 4.4, width: int = 520, height: int = 480, style: str = 'elemental', show_hidden_edges: bool = True, golden_polygons_3d: list[list[tuple[float, float, float]]] | None = None, graphic_id: str = 'g1') -> str

   Renders a 3D polyhedral solid to publication-grade theme-adaptive SVG.

   Uses orbit camera perspective projection with depth-sorted painter's
   algorithm, back-face culling, and directional lighting.

   :param solid: Exact symbolic Solid3D polyhedral model.
   :param yaw_deg: Horizontal orbit yaw angle in degrees.
   :param pitch_deg: Vertical orbit pitch angle in degrees.
   :param roll_deg: Camera roll angle in degrees.
   :param camera_dist: Orbit distance from model center.
   :param focal_length: Perspective camera focal length.
   :param width: SVG viewport width in pixels.
   :param height: SVG viewport height in pixels.
   :param style: Visual style ('elemental', 'woodcut_vacuum', 'woodcut_solidum').
   :param show_hidden_edges: Whether to render dashed back-facing edges.
   :param golden_polygons_3d: Optional list of 3D polygon vertex loops to render
                              as translucent golden planes depth-interleaved with faces.
   :param graphic_id: Unique identifier for data-graphic-id attribute.

   :returns: Valid XML SVG string with class 'euclid-graphic'.

   :raises ValueError: If style is unknown or solid has no vertices.
